## 8.1-2 — Signed-URL expiry + single-use drill

- `DOC_URL_TTL_MS` env (routes sign + TOKEN_KINDS; default 15 min); issue-time guard
  refuses < 60 s in production.
- Single-use is now ATOMIC on PG: `UPDATE one_time_tokens SET consumed_at=$1 WHERE
  kind=$2 AND token_hash=$3 AND consumed_at IS NULL AND expires_at > $1 RETURNING *`
  (`pg-repos.tokens.consumeAtomic`; JSON store keeps the sequential path). The 401/409
  distinction is preserved (expired vs already-used) via a follow-up read.
- Drills (portal started with `DOC_URL_TTL_MS=60000`):
  - E1: fresh token → **200**; immediate second fetch → **409** `Token already used`. ✔
  - E2: fresh token, 62 s wait → **401** `Token expired`. ✔
  - E3: 10 PARALLEL fetches of one fresh token → codes
    `200,409,409,409,409,409,409,409,409,409` — **exactly one 200**. ✔
