
## 6. File Specifications

### 6.1 SVG Requirements

| Parameter | Specification |
|-----------|--------------|
| **ViewBox** | `0 0 {natural_width} {natural_height}` |
| **XML Namespace** | `xmlns="http://www.w3.org/2000/svg"` |
| **Minification** | SVGO optimized (remove comments, metadata, editor data) |
| **Embedded Fonts** | None; convert text to paths (outlines) |
| **Accessibility** | `<title>` and `<desc>` elements present |
| **Responsive** | `width="100%" height="100%"` (no fixed dimensions in SVG element) |

### 6.2 PNG Requirements

| Parameter | Specification |
|-----------|--------------|
| **Color Mode** | RGBA (with alpha transparency) |
| **Bit Depth** | 8-bit per channel (24-bit RGB + 8-bit alpha) |
| **Compression** | Lossless (PNG-24) |
| **DPI** | 72 DPI (web); 300 DPI (print variant stored separately) |

### 6.3 Naming Convention

```
{brand_slug}_{variant}.{ext}

Examples:
  simal-technologies_horizontal-fullcolor.svg
  hikvision_white_1x.png
  western-digital_fullcolor_2x.png
  unierp_fullcolor.svg
  simal-technologies_icon-only.svg
```

## 7. Usage Guidelines

### 7.1 Common Display Contexts

| Context | Brand Logo Variant | Size (CSS) |
|---------|-------------------|------------|
| **Website Header** | Full Color, Horizontal | `height: 40px` |
| **Website Footer — Primary** | Simal Technologies White | `height: 36px` |
| **Website Footer — Partner Grid** | Partner Brand Full Color | `height: 28px` |
| **Brand Listing Page — Cards** | Partner Brand Full Color | `height: 48px` |
| **Brand Detail Page — Hero** | Partner Brand Full Color | `height: 64px` |
| **B2B Portal — Product Lines** | Partner Brand Full Color | `height: 24px` |
| **Invoice / Quote PDF** | Simal Technologies Monochrome | `height: 50px` |
| **Email Signature** | Simal Technologies Full Color | `width: 180px` |
| **Social Media Avatar** | Simal Technologies Icon-Only | 400 x 400 px |
| **Favicon** | Simal Technologies Icon-Only | 32 x 32 px |

### 7.2 Do's and Don'ts

| YES — DO | NO — DON'T |
|-----------|------------|
| Maintain aspect ratio when scaling | Stretch, squash, or distort logos |
| Use authorized color variants only | Recolor partner brand logos |
| Ensure clear space around logos | Place logos on clashing backgrounds |
| Use SVG format for web whenever possible | Use low-resolution raster for large displays |
| Include (R) symbol where brand requires | Remove or obscure trademark symbols |
| Follow each brand's individual usage guide | Rotate, add effects (drop shadow, glow) |

### 7.3 CSS Implementation

```css
/* Default: SVG with PNG fallback */
.brand-logo {
  display: inline-block;
  height: 40px;
  width: auto;
}

.brand-logo img {
  height: 100%;
  width: auto;
  object-fit: contain;
}

/* Dark background variant */
.footer-dark .brand-logo-simal {
  /* Use white variant */
}

/* Responsive scaling */
@media (max-width: 768px) {
  .brand-logo {
    height: 32px;
  }
}
```

## 9. Logo Delivery Checklist

### 9.1 Pre-Delivery QA

- [ ] All SVG files validate against W3C SVG 1.1 spec
- [ ] All SVG files are SVGO-optimized and ≤ 20 KB
- [ ] All PNG files have transparent backgrounds (no white box around logo)
- [ ] PNG 2x files are exactly double the dimensions of 1x
- [ ] Color variants verified: Full Color, White, Monochrome (where applicable)
- [ ] Icon-only variants delivered for Simal Technologies and UniERP
- [ ] Arabic localized logo verified by native Arabic speaker
- [ ] All file names follow naming convention
- [ ] Copyright/trademark metadata embedded in file properties
- [ ] Files tested in: Chrome, Firefox, Safari, Edge (latest versions)

### 9.2 Post-Deployment QA

- [ ] Logos render correctly in website header (all pages)
- [ ] Logos render correctly in website footer (all pages)
