## 3. Production Approach

### 3.1 Recording Setup

| Element | Specification |
|---------|--------------|
| **Demo Instance** | Dedicated UniERP demo environment with sample data (Demo Trading LLC) |
| **Screen Recording** | OBS Studio — 1920×1080, 30 fps, lossless quality preset |
| **Mouse Cursor** | Enlarged cursor with click animation (yellow circle highlight) |
| **Browser** | Chrome, clean profile, no bookmarks bar, no extensions visible |
| **Picture-in-Picture** | Optional: presenter in corner (10% of frame), green screen background |

### 3.2 Post-Production

| Step | Description |
|------|-------------|
| 1. **Edit** | Cut screen recording to match narration pacing; remove dead time |
| 2. **Zoom & Pan** | Add Ken Burns-style zooms to highlight important UI elements |
| 3. **Annotations** | Animated circles, arrows, and highlights to draw attention |
| 4. **Voice-Over Sync** | Align narration with screen action precisely |
| 5. **Music** | Subtle background track; ducked under narration (-18 dB) |
| 6. **Subtitles** | EN burned-in (optional); AR/FR/RU as closed captions |
| 7. **Review** | UniERP Product Manager + Marketing Director approval |
