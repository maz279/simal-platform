## 2. Global Photography Standards

### 2.1 Technical Specifications

| Parameter | Specification |
|-----------|--------------|
| **Camera** | Full-frame DSLR/mirrorless, minimum 24 MP (e.g., Sony A7R V, Canon EOS R5) |
| **Lens** | 100mm f/2.8 macro for detail; 50mm f/1.4 for hero; 24-70mm f/2.8 for lifestyle |
| **Sensor Resolution** | 6000 × 4000 px minimum (24 MP) |
| **Color Space** | sRGB IEC61966-2.1 for web delivery |
| **Color Depth** | 8-bit per channel (24-bit RGB) |
| **DPI** | 72 DPI for web; 300 DPI for print archive |
| **File Format — Master** | TIFF (16-bit, uncompressed) — archived internally |
| **File Format — Web Delivery** | WebP (primary) + JPEG (fallback) |
| **JPEG Quality** | 82-85% (balance of quality vs. file size) |
| **WebP Quality** | 80% (lossy) |
| **Background** | Pure white: RGB(255, 255, 255) — #FFFFFF |
| **Lighting** | 3-point studio lighting: key, fill, backlight; 5500K daylight-balanced |

### 2.2 Resolution Variants

Every product image is delivered in **4 resolution breakpoints**:

| Variant | Width | Height | Primary Use | Max File Size |
|---------|-------|--------|-------------|---------------|
| **Thumbnail** | 150 px | 150 px (square crop) | Category grids, search results, B2B order lines | ≤ 15 KB |
| **Small** | 300 px | 300 px (square crop) | Product cards on mobile, related products | ≤ 30 KB |
| **Medium** | 600 px | 600 px (square crop) | Product detail page primary, catalog listings | ≤ 80 KB |
| **Large** | 1200 px | 1200 px (square crop) | Lightbox zoom, full-screen gallery | ≤ 200 KB |
| **Full (Archive)** | 2400 px | 2400 px+ (native ratio) | Print catalog, trade show banners, master archive | No limit |

### 2.3 Aspect Ratio Policy

- **Hero (white background):** 1:1 square (cropped from native)
- **Angle shots:** 1:1 square (cropped from native)
- **Lifestyle/Context:** 16:9 landscape or 4:5 vertical (as appropriate)
- **Packaging:** 3:4 (portrait) for retail box; 1:1 for front/back flat lay
- **Native/master files:** Preserve original sensor ratio (3:2 typically)

## 3. Shot Types Per Product

### 3.1 Hero Shot (White Background)

**Quantity:** 1 per product (76 total)

| Element | Specification |
|---------|--------------|
| **Background** | Pure white #FFFFFF, seamless infinity curve |
| **Product Position** | Centered, floating at 10°–15° from vertical |
| **Lighting** | Even, shadowless; no hotspots or blown highlights |
| **Reflections** | Controlled; use polarizing filter for glossy surfaces |
| **Scale Reference** | No physical scale marker; dimension overlay added in post |
| **Post-Processing** | Background cutout to pure white; color calibration per Pantone match; dust/blemish removal; edge sharpening |

### 3.2 Lifestyle / Context Shot

**Quantity:** 1 per product (76 total)

| Element | Specification |
|---------|--------------|
| **Setting** | Realistic usage environment per product category |
| **Props** | Complementary items (e.g., laptop + docking station + monitor) |
| **Lighting** | Natural + fill, warm ambient tone (4800–5200K) |
| **Depth of Field** | f/2.8–f/4.0; product in sharp focus, background softly blurred |
| **Human Element** | Hands/partial person interacting with product (optional, per brand guidelines) |
| **Examples by Category** | → SSD: on desk next to laptop with transfer cable visible; → Security camera: mounted on exterior wall with sky visible; → Monitor: on desk showing vibrant content, keyboard/mouse in frame |

### 3.3 Angle Shot Set (4 Angles)

**Quantity:** 4 per product (304 total)

| Angle | Description | Camera Position |
|-------|-------------|-----------------|
| **Front (0°)** | Straight-on front view | Camera at product center height, perpendicular |
| **45° Front** | Three-quarter front perspective | Camera 45° left of center, elevated 15° |
| **Back / Rear** | Straight-on rear view (ports, labels, model numbers) | Camera at product rear center height |
| **Side Profile** | Left or right side (choose side with most visual interest) | Camera at product side, perpendicular |

**Special Cases:**
- **Products with cables/connectors (UGREEN):** Include one shot showing all ports populated with cables
- **Products with screens (Koorui monitors, HIKVISION NVR):** Include one shot with screen powered on, displaying content
- **SSD/RAM (Crucial, TEAMGROUP, GSKILL):** Include one macro close-up of label/specs at 1:1 magnification

### 3.4 Packaging Shot

**Quantity:** 1 per product (76 total)

| Element | Specification |
|---------|--------------|
| **Angle** | Front of retail box, flat lay, slight forward tilt (5°) |
| **Background** | White #FFFFFF or complementary brand color backdrop |
| **Condition** | Mint/sealed packaging; no dents, tears, or price stickers |
| **Labels** | Ensure barcode, SKU, and regulatory marks are legible |

## 5. Post-Processing Workflow

### 5.1 Standard Edit Pipeline

```
RAW Capture
    │
    ▼
Step 1: Color Calibration
    ├── White balance to 5500K
    ├── Exposure correction (±0.5 EV)
    ├── Color checker passport reference
    └── sRGB conversion
    │
    ▼
Step 2: Background Processing
    ├── Mask subject from background
    ├── Replace background with pure #FFFFFF
    ├── Feather edge: 1–2 px for seamless blend
    └── Check for edge halos; remove if present
    │
    ▼
Step 3: Retouching
    ├── Dust/blemish removal (spot healing brush)
    ├── Reflection control (if needed, clone stamp)
    ├── Edge sharpening (unsharp mask: 0.8 px, 85%)
    └── Noise reduction (if ISO > 400)
    │
    ▼
Step 4: Cropping & Framing
    ├── Crop to 1:1 for hero/angle shots
    ├── Center product with 5% padding on all sides
    ├── Ensure uniform product scale within each brand
    └── Verify horizon/alignment is perfectly level
    │
    ▼
Step 5: Export Pipeline
    ├── Export 2400px TIFF (master archive)
    ├── Generate 4 responsive variants (1200, 600, 300, 150 px)
    ├── Output WebP (primary) at Q=80
    ├── Output JPEG (fallback) at Q=82
    ├── Strip EXIF metadata (except copyright + description)
    └── Run through ImageOptim / TinyPNG for final compression
```

### 5.2 Naming Convention

```
{brand_slug}_{product_sku}_{shot_type}_{variant}.{ext}

Examples:
  hikvision_ds-2cd2387g2_hero_1200.webp
  crucial_ct1000t500ssd8_angle-front_600.jpg
  koorui_24e4_lifestyle_1200.webp
  ugreen_cm475_packaging_600.jpg
  western-digital_wdblack-sn850x_angle-45_300.jpg
```

## 7. Quality Assurance Checklist

### 7.1 Per-Image QA

- [ ] Background is pure #FFFFFF (verified with eyedropper at 4 corners)
- [ ] No dust, scratches, fingerprints visible on product
- [ ] Product is centered within ±2% of frame center
- [ ] Horizons and vertical lines are perfectly aligned
- [ ] No color fringing or chromatic aberration visible at 100% zoom
- [ ] Exposure is even; no clipped highlights (255) or crushed shadows (0)
- [ ] Reflection of photographer/studio equipment removed
- [ ] File size within limits for each resolution variant
- [ ] WebP and JPEG versions are visually identical at standard viewing
- [ ] Naming convention strictly followed

### 7.2 Cross-Brand Consistency QA

- [ ] All products within same category appear at consistent scale
- [ ] White balance is consistent across all images (±200K)
- [ ] Padding/margins around product are uniform (±2%)
- [ ] Shadow intensity is consistent (or absent if shadowless)
- [ ] Angle shots are consistently framed across all brands

## 9. Accessibility Compliance

All product images must meet **WCAG 2.1 Level AA** standards:

- **Alt text:** Every `<img>` contains a descriptive alt attribute identifying the product name, model, and shot type
- **Decorative duplicates:** If a product image is purely decorative (duplicate), use `alt=""`
- **Color contrast:** Any text overlaid on lifestyle images meets 4.5:1 contrast ratio
- **Text in images:** Avoid embedding text in product photographs; use HTML overlay instead
- **SVG diagrams:** Any specification diagrams within images should also have an accessible text description nearby
