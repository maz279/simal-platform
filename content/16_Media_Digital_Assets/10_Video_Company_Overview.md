## 1. Overview

A professional 2–3 minute corporate overview video serves as the cornerstone of Simal Technologies' visual storytelling. It communicates the company's mission, scale, capabilities, and values to prospective clients, partners, and employees — embedded on the About Us page and used across social media and presentations.

### 1.1 Video Specifications

| Parameter | Specification |
|-----------|--------------|
| **Duration** | 2:00–3:00 minutes |
| **Aspect Ratio** | 16:9 (primary); 1:1 and 9:16 (social cuts) |
| **Resolution** | 1920×1080 (Full HD); 3840×2160 (4K master) |
| **Frame Rate** | 24 fps (cinematic) or 30 fps |
| **Codec** | H.264 (web); H.265/HEVC (archive master) |
| **Audio** | AAC 320 kbps, 48 kHz stereo |
| **Hosting** | YouTube (primary, unlisted or public) + Vimeo (backup, embed) |
| **Subtitles** | EN (burned-in optional); AR, FR, RU (closed captions) |

## 5. Post-Production

### 5.1 Editing Workflow

```
1. Ingest & Organize (Day 1)
2. Rough Cut — Assemble scenes in sequence (Days 2–3)
3. Fine Cut — Timing, pacing, transitions (Days 4–5)
4. Color Grade — Consistent look across all scenes (Day 6)
5. Sound Mix — Narration, ambient, background music (Days 7–8)
6. Motion Graphics — Logo animation, maps, text overlays (Days 8–9)
7. Subtitles — EN burned-in; AR/FR/RU CC files (Day 10)
8. Review — Internal team review (Day 11)
9. Revisions — Incorporate feedback (Days 12–13)
10. Final Delivery (Day 14)
```

### 5.2 Music

| Element | Specification |
|---------|--------------|
| **Style** | Modern corporate, Middle Eastern undertones, inspiring but not aggressive |
| **Tempo** | 100–120 BPM (energetic but not rushed) |
| **License** | Royalty-free or custom composed; perpetual web use license |
| **Source** | Artlist.io, Epidemic Sound, or custom composer |

### 5.3 Color Grade

- **Overall:** Warm, cinematic, slightly desaturated shadows
- **Brand moments:** Teal/orange complementary palette
- **Office/indoor:** Clean whites, natural skin tones
- **Warehouse:** Industrial, earth tones, contrasty

### 7.3 Lazy Loading

```javascript
// Intersection Observer for lazy loading video iframe
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const iframe = entry.target;
      iframe.src = iframe.dataset.src;
      observer.unobserve(iframe);
    }
  });
}, { rootMargin: '200px' });

document.querySelectorAll('iframe[data-src]').forEach(iframe => {
  observer.observe(iframe);
});
```
