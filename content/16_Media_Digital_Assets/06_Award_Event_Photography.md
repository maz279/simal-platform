## 8. Technical Specifications

### 8.1 Photography Standards

| Parameter | Award Ceremonies | Trade Shows | Corporate Events |
|-----------|-----------------|-------------|-----------------|
| **Resolution** | 2400 × 1600 px min | 2400 × 1600 px min | 2400 × 1600 px min |
| **Style** | Formal, documentary | Commercial, energetic | Warm, celebratory |
| **Lighting** | Available venue light; bounce flash | Exhibition hall lighting; fill flash | Ambient; flash for group shots |
| **Lens** | 24–70mm f/2.8 + 70–200mm f/2.8 | 24–70mm f/2.8 + 16–35mm f/2.8 | 24–70mm f/2.8 |
| **Flash** | Bounce flash (ceiling) | Direct fill (high ceilings) | Bounce flash |
| **Format** | RAW + JPEG | RAW + JPEG | RAW + JPEG |

### 8.2 Post-Processing

- Consistent color grade across all event photos
- Red-eye removal
- Background cleanup (remove distracting elements if possible)
- No heavy filters — maintain documentary authenticity
- Watermark: Subtle Simal Technologies mark in corner (for public/social media use)

### 8.3 File Naming

```
{event_slug}_{date}_{shot-number}.{ext}

Examples:
  hiksemi-award-2025_01_trophy-handover.webp
  gitex-2025_03_stand-wide.webp
  intersec-2026_05_product-display.jpg
  annual-gala-2025_08_group-photo.webp
  hikvision-partner-award-2025_02_ceremony.webp
```

## 11. Event Photography Checklist

### Pre-Event

- [ ] Event confirmed in calendar 4+ weeks ahead
- [ ] Photographer booked (internal or external)
- [ ] Shot list provided to photographer
- [ ] Venue photography policy checked
- [ ] Branded backdrop/banner prepared (Simal logo)
- [ ] Backup camera + batteries + memory cards
- [ ] Social media live-coverage plan (if applicable)

### During Event

- [ ] Arrive early for venue/scene-setting shots
- [ ] Capture all key moments from shot list
- [ ] Get group shots early (before people leave)
- [ ] Take detail shots (trophies, branding, food, decor)
- [ ] Capture candid networking moments

### Post-Event

- [ ] Select and edit top 20–40 photos within 48 hours
- [ ] Upload to shared drive / DAM system with proper naming
- [ ] Share with Marketing for social media within 24 hours
- [ ] Archive RAW files for future use
- [ ] Send thank-you photos to partner brand contacts (if applicable)
