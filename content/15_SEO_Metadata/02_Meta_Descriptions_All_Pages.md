## Meta Description Rules & Best Practices

| Rule | Guideline |
|---|---|
| **Unique per page** | Every page must have a distinct description — no duplicates |
| **Length** | 150–160 characters (including spaces). Google displays ~920px width (≈155–160 chars on desktop, ~120 on mobile) |
| **Active Voice + CTA** | End with a clear call-to-action: "Browse", "Contact us", "Learn more", "Get a quote", "Explore" |
| **Primary Keyword** | Include primary keyword naturally within first 25 characters |
| **Secondary Keywords** | Include 1–2 secondary keywords naturally |
| **Value Proposition** | Answer: "Why should the user click this result?" |
| **No Quotes** | Avoid double quotes (") — Google may truncate at the quote |
| **Match Content** | Description must accurately reflect actual page content (Google may rewrite mismatched descriptions) |
| **Language-Specific** | Each language has fully translated descriptions (not machine-translated) |

## Meta Description Validation Rules

| Check | Rule |
|---|---|
| **Uniqueness** | No duplicate descriptions across any two pages |
| **Length** | 150–160 characters (warn at <120 or >165) |
| **CTA Present** | Must contain at least one call-to-action phrase |
| **Primary Keyword** | Primary keyword must appear within first 25 characters |
| **No Truncation** | Description must display completely in SERP without "..." |
| **Active Voice** | Use active, not passive voice ("Browse our catalog" not "Our catalog can be browsed") |
| **Mobile Preview** | Test at 120-char truncation for mobile SERP — key message must survive truncation |
| **Language Match** | Description language must match page `lang` attribute |

## Frequently Asked Questions

**Q: What happens if a meta description is too long?**
A: Google truncates descriptions at approximately 155–160 characters (desktop) or ~120 characters (mobile). Text after the truncation point is replaced with "...". Always place the key message and CTA within the first 120 characters to survive mobile truncation.

**Q: Can I leave the meta description blank and let Google generate it?**
A: Not recommended. While Google sometimes rewrites descriptions, providing a well-crafted description gives you control over the message shown in search results. Our policy: every page must have a manually written description.

**Q: Should product descriptions include prices?**
A: No. Prices change frequently and outdated prices in SERP descriptions create a poor user experience. Instead, use phrases like "wholesale pricing" or "competitive prices" that don't go stale.

**Q: How often are meta descriptions reviewed?**
A: Quarterly, alongside meta titles. Descriptions for high-traffic pages are A/B tested for CTR optimization using Google Search Console data.
