# 03 Reporting Dashboard

> **Platform:** Google Looker Studio (primary) + GA4 Standard Reports
> **Audience:** Marketing Team, Sales Leadership, Management
> **Last Updated:** May 2, 2026

---

## Dashboard Reports

### Executive Dashboard (Monthly)

| Widget | Data Source | Metrics |
|---|---|---|
| Total Website Traffic | GA4 | Users, Sessions, Pageviews (MoM %) |
| Traffic by Country | GA4 | Top 10 countries |
| B2B Registrations | GA4 + HubSpot | Count, Approval Rate |
| RFQ Submissions | GA4 + HubSpot | Count, Total Value |
| Demo Requests | GA4 + HubSpot | Count, Conversion Rate |
| Top Products Viewed | GA4 | Product name, views |
| Conversion Rate | GA4 | Overall + per channel |

### Marketing Dashboard (Weekly)

| Widget | Data Source | Metrics |
|---|---|---|
| Traffic by Channel | GA4 | Organic, Direct, Referral, Social, Email, Paid |
| Top Landing Pages | GA4 | URL, Entrances, Bounce Rate |
| SEO Performance | GSC | Clicks, Impressions, CTR, Avg Position |
| Email Performance | Mailchimp | Sent, Opened, Clicked, Unsubscribed |
| Social Performance | Native + GA4 | Followers, Engagement, Referral Traffic |

### Sales Dashboard (Weekly)

| Widget | Data Source | Metrics |
|---|---|---|
| B2B Pipeline | HubSpot | Deals Created, Deal Value, Stage Distribution |
| RFQ to Quote Rate | HubSpot | % of RFQs converted to Quotes |
| Quote to Order Rate | HubSpot | % of Quotes converted to Orders |
| Order Value | GA4 + ERP | Total Order Value, Avg Order Value |
