## How Regional Orders Work

```
Customer Inquiry (from region)
    → Dubai HQ processes inquiry
    → Sales team provides quotation (including shipping estimate)
    → Customer confirms order + payment (TT/LC)
    → Order prepared at JAFZA warehouse
    → Export documentation prepared (COO, Invoice, Packing List, AWB/BL)
    → Shipment dispatched (Air or Sea)
    → Tracking information shared
    → Customer receives goods + handles local customs clearance
```

### Documentation Provided with Every Shipment

| Document | Purpose |
|----------|--------|
| **Commercial Invoice** | Declares product value, description, and terms of sale |
| **Packing List** | Details contents, weights, dimensions of each package |
| **Certificate of Origin** | Verifies country of manufacture/origin (issued by Dubai Chamber) |
| **Air Waybill (AWB) / Bill of Lading (BL)** | Shipping document with tracking |
| **Product Datasheets / Compliance Certs** | Per customer request or as required by destination country |
