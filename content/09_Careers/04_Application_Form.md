## Form Behavior & Validation

### Field Validation Rules

| Field | Rule | Error Message |
|-------|------|-------------|
| Full Name | Minimum 2 words, letters only (including accented characters) | "Please enter your full name as per your official ID." |
| Email | RFC 5322 compliant email format | "Please enter a valid email address." |
| Phone | Valid international format with country code | "Please enter a valid phone number with country code (e.g., +971 50 123 4567)." |
| LinkedIn URL | Must start with "https://linkedin.com/in/" | "Please enter a valid LinkedIn profile URL." |
| CV Upload | PDF or DOC, max 5MB | "Please upload a PDF or DOC file under 5MB." |
| Cover Letter (Text) | Max 3,000 characters | "Your cover letter exceeds the 3,000 character limit." |
| Years of Experience | Must be a non-negative number | "Please enter a valid number of years." |
| Salary (Numeric) | Positive number only | "Please enter a valid expected salary amount." |

### Submission Flow

```
User clicks "Submit Application"
    → Client-side validation (all required fields)
    → reCAPTCHA verification
    → If validation fails: inline error messages on failed fields, scroll to first error
    → If validation passes:
        → Disable submit button (prevent double submission)
        → Show loading spinner
        → POST form data to /api/careers/apply (multipart/form-data)
        → On success (HTTP 200):
            → Display success message: "Thank you for your application! We have sent a confirmation email to {email}. Our HR team will review your application and contact you within 5-7 business days if shortlisted. Reference ID: {auto-generated-id}"
            → Trigger Google Analytics / HubSpot conversion event
            → Trigger confirmation email to candidate
            → Notify HR team via internal Slack/email
        → On error (HTTP 4xx/5xx):
            → Display error message: "Something went wrong. Please try again or email your application to careers@simalme.com."
            → Log error details for debugging
```

## Post-Submission

### Success Page

After successful submission, the user sees:

- **Confirmation Message:** Thank you with application reference number
- **What Happens Next:** Brief timeline of review process
- **Related Links:** View other openings, Learn more about Simal, Follow us on LinkedIn
- **Email Confirmation:** Auto-sent to candidate's email with application summary

### Confirmation Email Template

**Subject:** Application Received — {Job Title} (Ref: {Application Ref ID})

**Body:**
```
Dear {Candidate Name},

Thank you for applying for the position of {Job Title} at Simal Technologies Middle East LLC.

Your application reference number is: {REF-ID}

What's next:
1. Our HR team will review your application within 5-7 business days.
2. If your profile matches our requirements, we will contact you to schedule an initial phone/video screening.
3. Due to the volume of applications, we are unable to provide individual feedback to candidates who are not shortlisted.

If you have any questions in the meantime, feel free to reach out to us at careers@simalme.com.

We appreciate your interest in joining Simal Technologies.

Best regards,
HR Department
Simal Technologies Middle East LLC
www.simalme.com
```
