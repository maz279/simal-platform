## Write Like Simal — Our Content Standards

This style guide ensures every piece of Simal Technologies content — from product descriptions to white papers — is consistent, professional, and on-brand. All content creators, agencies, and partners should follow these standards.

---

## Brand Voice & Tone

### Voice Characteristics

| Characteristic | Description |
|---|---|
| **Professional** | We're serious about IT, ERP, and business. Our content reflects domain expertise. |
| **Confident** | We know our products and solutions. We state facts without hedging. |
| **Helpful** | We exist to help customers make better decisions. Content is useful before it's promotional. |
| **Approachable** | Technical doesn't mean complicated. We explain concepts clearly without jargon. |
| **Trustworthy** | 20+ years in business. Our content builds trust through accuracy and transparency. |

### Tone by Content Type

| Content Type | Tone |
|---|---|
| **Product Descriptions** | Technical, precise, benefit-focused |
| **Blog Posts** | Informative, conversational, insightful |
| **White Papers** | Authoritative, research-backed, formal |
| **Case Studies** | Story-driven, results-focused, credible |
| **Website Pages** | Professional, clear, action-oriented |
| **Social Media** | Engaging, concise, timely |
| **Email Newsletters** | Warm, informative, personal |

## Grammar & Style Conventions

| Rule | Convention |
|---|---|
| **English Variant** | US English (e.g., "color" not "colour", "optimize" not "optimise") |
| **Currency** | USD for international pricing; AED for UAE-specific pricing; BDT for Bangladesh pricing |
| **Numbers** | Spell out one through nine; use numerals for 10 and above. Use numerals for all measurements (5GB, 12 months) |
| **Dates** | Month Day, Year (e.g., "May 1, 2026") |
| **Company Name** | Always "Simal Technologies" on first mention; "Simal" acceptable on subsequent mentions |
| **Product Name** | UniERP (not UNIERP or Unierp); Odoo 19 CE (not Odoo 19 Community Edition on first mention) |
| **Headings** | Title Case for H1 and H2; Sentence case for H3 and below |
| **Bullet Lists** | No punctuation at end unless the item is a complete sentence |
| **Oxford Comma** | Use it (e.g., "SSDs, RAM, and GPUs") |
| **Em Dashes** | Use em dash (—) without spaces for parenthetical breaks |
| **Quotation Marks** | Double quotes for speech/quotes; single quotes for terms |

## Blog Post Guidelines

| Element | Guideline |
|---|---|
| **Length** | 800–2,000 words |
| **Title** | 50–70 characters; include primary keyword; use colon or dash for subtitle |
| **Meta Description** | 150–160 characters; include primary keyword; compelling reason to click |
| **Structure** | H2 for main sections, H3 for sub-sections. Use bullet lists, tables, and callouts for scannability |
| **Images** | At least 1 featured image (1200×630px) + 2–3 in-content images |
| **CTA** | Every post ends with a relevant CTA — demo, contact, download, or related article |
| **Internal Links** | 2–4 links to relevant Simal pages |
| **External Links** | 1–2 links to authoritative sources (no competitor links) |

## CTA Conventions

| Context | Preferred CTA |
|---|---|
| **ERP Content** | [Schedule a Free Demo →](/erp/demo) |
| **IT Hardware Content** | [Contact Sales →](/contact) or [Become a Reseller →](/partners/apply) |
| **Blog Posts** | Contextual — demo, related article, or newsletter subscription |
| **Email** | Single primary CTA per email |

## Arabic Adaptation Guide

| Element | Guideline |
|---|---|
| **Translation** | Professional human translation — not machine translation |
| **Tone** | Formal Arabic (Fus-ha) for website; slightly more conversational for social media |
| **Layout** | RTL (Right-to-Left) for Arabic pages. Mirror all layouts, icons, and CTAs |
| **Numbers** | Arabic-Indic numerals for Arabic content |
| **Cultural Sensitivity** | Review all imagery and examples for cultural appropriateness in GCC context |

## SEO Checklist

For every content page:

- [ ] Target keyword in Title (H1)
- [ ] Target keyword in first 100 words
- [ ] Meta title: 50–60 characters, includes brand name
- [ ] Meta description: 150–160 characters, includes keyword and CTA
- [ ] URL slug: short, keyword-rich, hyphenated
- [ ] H2 and H3 tags used hierarchically
- [ ] Alt text on all images
- [ ] Internal links to 2–4 relevant pages
- [ ] External links to 1–2 authoritative sources
- [ ] Canonical URL set
- [ ] OG image specified (1200×630px)
- [ ] Schema markup applied (Article, Product, FAQ, etc.)
- [ ] Page load < 3 seconds (check with PageSpeed Insights)
