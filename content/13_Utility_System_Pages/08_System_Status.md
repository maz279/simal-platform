## Service Status Definitions

| Status | Icon | Indicator | Description |
|---|---|---|---|
| **Operational** | 🟢 | Green | Service is functioning normally with no degradation |
| **Degraded Performance** | 🟡 | Yellow/Amber | Service is operational but experiencing slower-than-normal response times or intermittent issues |
| **Partial Outage** | 🟠 | Orange | Service is available but some features or regions are affected |
| **Major Outage** | 🔴 | Red | Service is completely unavailable to all users |
| **Under Maintenance** | 🔵 | Blue | Service is temporarily offline for planned maintenance |

## Incident Severity Levels

| Level | Label | Response SLA | Notification Channel |
|---|---|---|---|
| **P1** | Critical — Major Outage | Response ≤ 5 min, Resolution ≤ 1 hour | SMS + Email + Status Page Banner |
| **P2** | High — Partial Outage | Response ≤ 15 min, Resolution ≤ 4 hours | Email + Status Page |
| **P3** | Medium — Degraded Performance | Response ≤ 30 min, Resolution ≤ 8 hours | Email + Status Page |
| **P4** | Low — Minor Issue | Response ≤ 2 hours, Resolution ≤ 24 hours | Status Page |

## Frequently Asked Questions

**Q: How quickly will I be notified of an outage?**
A: P1 (Critical) incidents trigger notifications within 5 minutes of detection. Email subscribers receive alerts immediately; SMS subscribers receive alerts for P1 incidents only.

**Q: Can I integrate the status data into my own dashboard?**
A: Yes. Our public REST API (api.status.simalme.com/v1) provides JSON-formatted status data. API keys are not required for read-only status queries.

**Q: What happens if the status page itself goes down?**
A: The status page is hosted on infrastructure completely independent from our main website. In the extremely unlikely event both go down, a static fallback page is served from a tertiary CDN with emergency contact information.

**Q: How do I report an issue that's not showing on the status page?**
A: If you're experiencing an issue not reflected on the status page, please email support@simalme.com or open a ticket via the B2B portal. Include your account details and a description of the issue.

**Q: Are maintenance windows always at night (GST)?**
A: Yes. We schedule all maintenance during low-traffic windows: 02:00–06:00 GST (UTC+4) on weekends (Saturday–Sunday) whenever possible. Emergency maintenance may occur outside these windows with as much advance notice as practical.
