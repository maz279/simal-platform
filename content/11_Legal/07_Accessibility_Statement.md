## Our Commitment

Simal Technologies Middle East LLC is committed to ensuring digital accessibility for people of all abilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards to ensure our website is inclusive and accessible to the widest possible audience.

This commitment aligns with:
- **UAE Federal Decree-Law No. 45 of 2021** on the Protection of Personal Data, which emphasizes non-discrimination and inclusive access to digital services
- **UAE National Policy for Empowering People of Determination** — supporting the UAE's vision for an inclusive society
- **Dubai Disability Strategy 2025** — ensuring Dubai is a disability-friendly city

---

## Conformance Status

This website is designed to conform with the **Web Content Accessibility Guidelines (WCAG) 2.1 Level AA**. WCAG defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

**Target Conformance:** WCAG 2.1 Level AA  
**Current Status:** Partially conformant — continuous improvement in progress

## Accessibility Features Implemented

### Navigation & Structure

| Feature | Description |
|---------|------------|
| **Semantic HTML** | Proper use of heading hierarchy (H1-H6), landmark regions (header, nav, main, footer, aside), and ARIA landmarks |
| **Keyboard Navigation** | All interactive elements (links, buttons, forms, menus) are operable via keyboard alone |
| **Skip Navigation Link** | "Skip to main content" link available as the first focusable element on each page |
| **Consistent Navigation** | Navigation menus and page layouts are consistent across the website |
| **Breadcrumb Navigation** | Breadcrumb trails on all interior pages for orientation |
| **Sitemap** | XML and HTML sitemaps available for programmatic and user navigation |

### Visual Design

| Feature | Description |
|---------|------------|
| **Color Contrast** | Text and interactive elements meet minimum contrast ratios: 4.5:1 for normal text, 3:1 for large text |
| **Non-Color Indicators** | Information is not conveyed by color alone; icons, underlines, and patterns supplement color cues |
| **Resizable Text** | Text can be resized up to 200% without loss of content or functionality |
| **Responsive Design** | Website adapts to different screen sizes and orientations (mobile, tablet, desktop) |
| **Focus Indicators** | Visible focus outline on all keyboard-focusable elements |

### Content & Media

| Feature | Description |
|---------|------------|
| **Alt Text for Images** | All meaningful images include descriptive alternative text |
| **Video Captions** | Videos include closed captions (where video content is present) |
| **Transcripts** | Text transcripts available for audio and video content |
| **Accessible Forms** | All form fields have associated labels, error messages are descriptive, and forms can be completed via keyboard |
| **Accessible Tables** | Data tables include header rows, captions, and proper markup for screen readers |
| **Link Descriptions** | Links include descriptive text (avoiding "click here" or "read more") |

### Technical

| Feature | Description |
|---------|------------|
| **Screen Reader Compatibility** | Tested with JAWS, NVDA, and VoiceOver screen readers |
| **Browser Compatibility** | Tested on Chrome, Firefox, Safari, and Edge (latest 2 versions) |
| **ARIA Attributes** | Appropriate ARIA roles, states, and properties used for dynamic content |
| **Error Prevention** | Form validation with clear error messages and suggestions for correction |
| **Session Timeout Warnings** | Users are warned before sessions expire with the option to extend |

## Known Limitations

Despite our best efforts to ensure accessibility, we acknowledge the following known limitations:

| Limitation | Impact | Mitigation | Target Fix |
|-----------|--------|-----------|-----------|
| **Third-Party Embeds (Google Maps)** | Map interaction may not be fully keyboard accessible | Alternative text-based address and directions provided | Q3 2026 |
| **PDF Documents** | Some downloadable PDFs may not be fully tagged for accessibility | HTML alternatives provided where possible; accessible PDFs prioritized for new documents | Q4 2026 |
| **Product Images** | Some product images from brand partners may lack detailed alt text | Reviewing and updating image alt text across all product pages | Q3 2026 |
| **Legacy Content** | Older blog posts and resources may not meet all WCAG 2.1 AA criteria | Priority remediation of high-traffic pages | Ongoing |
| **Video Content** | Some embedded videos may lack full transcripts | Transcripts being added for top-viewed videos | Q4 2026 |

We are actively working to address these limitations and welcome your feedback on specific issues you encounter.

- The URL (web address) of the page where you encountered the issue
- A description of the issue or barrier
- The device, browser, and any assistive technology you are using
- Your preferred method of response

## Enforcement Procedure

If you are not satisfied with our response to your accessibility concern, you have the right to escalate:

1. **Internal Escalation:** Request escalation to Simal Technologies senior management by emailing info@simalme.com with "Accessibility — Escalation" in the subject line.
2. **External:** Contact the relevant regulatory authority in your jurisdiction. In the UAE, the Ministry of Community Development oversees disability-related matters.
