### 2. Cloud Migration

| Service | Description |
|---|---|
| **Lift & Shift (Rehost)** | Move applications to cloud with minimal changes. Fastest migration path. Best for legacy applications that will be modernized later. |
| **Replatform** | Make minor cloud-optimized changes (e.g., move to managed database) without changing core application architecture. Good balance of speed and optimization. |
| **Refactor / Re-architect** | Redesign applications to be cloud-native — containers, microservices, serverless. Highest effort, highest long-term value. |
| **Data Migration** | Secure transfer of databases, file stores, and data warehouses to cloud. AWS DMS, Azure Database Migration Service, GCP Database Migration Service. |
| **Application Migration** | Move applications (web apps, ERP, custom software) to cloud with minimal downtime. Blue-green deployment or canary release strategies. |

## Frequently Asked Questions

**Q: How do we choose between AWS, Azure, and GCP?**
We evaluate based on your specific needs: existing Microsoft ecosystem (Azure), AI/ML and data analytics (GCP), broadest service catalog and global reach (AWS), or a multi-cloud approach. Our cloud readiness assessment provides an objective recommendation with cost projections for each option.

**Q: How long does a typical cloud migration take?**
Depends on complexity. A simple lift-and-shift of 5–10 servers: 4–6 weeks. A replatform with database migration: 8–12 weeks. A full re-architecture to cloud-native: 3–6 months. We provide a detailed migration plan and timeline after assessment.

**Q: What about data security and sovereignty — especially for UAE and Bangladesh regulations?**
All data can be hosted in-region: AWS (Bahrain, UAE regions), Azure (UAE Central, UAE North), GCP (Doha, Dammam). We configure data residency controls and encryption so your data never leaves the specified geography without your authorization.

**Q: Do you provide ongoing managed services after migration?**
Yes. Our managed cloud services cover 24/7 monitoring, patch management, backup, security, and performance optimization. SLAs range from 1-hour response (critical) to next-business-day (low priority). We become your cloud operations team.
